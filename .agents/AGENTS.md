# Workspace Styling Rules

1. **Typography**: Every text element must use typography classes defined in `styles/base/_typography.scss` (e.g. `kr_body_b`, `kr_caption`, `icon_14`, `icon_36`, etc.).
2. **Colors**: Every color reference must use color variables from `styles/abstracts/_colors.scss` (e.g. `colors.$color_white`, `colors.$color_tag_stroke`, etc.).
3. **Tag Stroke Buttons**: Button borders (such as Tag Stroke) use 1px inside stroke with `$color_tag_stroke` (`rgba(59, 64, 85, 0.6)` / `#3B4055 - 60%`).
